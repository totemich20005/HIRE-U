Diccionario de Datos - Base de Datos Hireu

Tabla: Empresa

Campo Tipo Restricción Descripción
EmpresaId INT PK, AUTO_INCREMENT Identificador único de la empresa
Nombre VARCHAR(150) NOT NULL Nombre de la empresa
Sector VARCHAR(100) - Sector económico
Descripcion TEXT - Descripción empresarial
Ubicacion VARCHAR(150) - Ubicación de la empresa
CorreoContacto VARCHAR(150) - Correo empresarial

Tabla: Egresado

Campo Tipo Restricción Descripción
EgresadoId INT PK, AUTO_INCREMENT Identificador del egresado
Nombre VARCHAR(100) NOT NULL Nombre del egresado
Apellido VARCHAR(100) - Apellido del egresado
CorreoInstitucional VARCHAR(150) - Correo institucional
ProgramaAcademico VARCHAR(100) - Programa académico
AnioGraduacion YEAR - Año de graduación
FotoPerfil VARCHAR(255) - Foto del egresado
PerfilProfesional TEXT - Descripción profesional

Tabla: OfertaLaboral

Campo Tipo Restricción Descripción
OfertaLaboralId INT PK Identificador de la oferta
EmpresaId INT FK Empresa que publica la oferta
Titulo VARCHAR(130) - Título de la vacante
Descripcion TEXT - Descripción de la vacante
Ubicacion VARCHAR(150) - Ubicación laboral
TipoContrato VARCHAR(100) - Tipo de contrato
Salario DECIMAL(12,2) - Salario ofrecido
FechaInicio DATE - Fecha de inicio
FechaFin DATE - Fecha de finalización
Estado VARCHAR(50) - Estado de la vacante

Tabla: Auditoria

Campo Tipo Restricción Descripción
AuditoriaId INT PK Identificador de auditoría
TablaAfectada VARCHAR(100) - Tabla modificada
AccionRealizada VARCHAR(50) - INSERT, UPDATE o DELETE
RegistroId INT - ID afectado
FechaMovimiento DATETIME DEFAULT CURRENT_TIMESTAMP Fecha del movimiento
UsuarioBD VARCHAR(100) - Usuario de MySQL
DescripcionMovimiento TEXT - Detalle del cambio
